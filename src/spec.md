# Specification

## Summary
**Goal:** Add Y-axis controls, sensor checkboxes, and a download button to the TSIC Loggers page.

**Planned changes:**
- Add Y-axis minimum and maximum input controls that allow users to set custom bounds for the graph (resets to automatic scaling on refresh)
- Add checkboxes in the graph legend to toggle individual sensors (S1-S72) on and off (all enabled by default on refresh)
- Add a download button linking to the Google Spreadsheet, styled to match the Conceptmachine page download button

**User-visible outcome:** Users can customize the Y-axis range, selectively show/hide individual sensors using checkboxes, and access the data spreadsheet via a download button on the TSIC Loggers page.
